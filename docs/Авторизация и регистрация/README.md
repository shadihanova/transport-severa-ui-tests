# Требования и преднастройки: Авторизация и регистрация

**Форма регистрации**
Для успешной отправки формы регистрации **обязательны к заполнению все 5 полей**: **Имя**, **Фамилия**, **Почта (Email)**, **Пароль**, **Повторите пароль**.

- Правила валидации полей формы:
  - Поля **Имя** и **Фамилия**: валидируются на длину **от 2 символов включительно** (кириллица/латиница).
  - Поле **Пароль**: валидируется на длину **не менее 5 символов включительно** (допустимы любые символы).
  - Поля **Пароль** и **Повторите пароль**: должны содержать **абсолютно идентичные значения**.
- Валидация полей происходит **«на лету»** (при вводе данных или потере фокуса полем). Если поле не прошло валидацию, **граница инпута подсвечивается красной рамкой**.
- При наличии хотя бы одного невалидного поля кнопка отправки формы блокируется, либо отправка формы прерывается.
- Подтверждение регистрации (через Email-ссылку или SMS-код) **не требуется**.
- При успешной регистрации выводится всплывающее уведомление (flash/toast): **зеленый баннер «Вы успешно зарегистрированы!»**.
- После успешной регистрации происходит автоматический редирект на модальное окно входа **/#/login**, при этом поля **Почта** и **Пароль** **автоматически предзаполнены** данными, указанными при регистрации.

**Форма авторизации**

- В качестве логина используется **Почта (Email)**.
- Лимит на количество неверных попыток входа **отсутствует** (блокировка аккаунта/капча не вызывается).
- Функция восстановления пароля (Forgot Password) в интерфейсе **отсутствует**.
- На форме авторизации доступен **чекбокс «Оставаться в системе»**:
  - Если чекбокс активен при входе, токен сессии сохраняется в постоянное хранилище браузера (LocalStorage), сессия сохраняется после закрытия/перезагрузки вкладки.
- При вводе неверных учетных данных выводится всплывающее уведомление об ошибке: **красный flash «Неверный логин или пароль»**.
- При успешном входе выводится **зеленый flash «Вход выполнен»**, окно авторизации закрывается, а в шапке/меню отображаются **иконка профиля**, **Имя Фамилия** пользователя и кнопка **«Выход»**.

**Быстрая авторизация через внешние сервисы (OAuth)**

- На формах входа и регистрации доступны кнопки быстрой авторизации: **«Войти через VK»** (VK ID) и **«Войти через Яндекс»** (Yandex ID).
- Нажатие на кнопку OAuth открывает соответствующее всплывающее окно провайдера. После успешного подтверждения прав происходит редирект в портал «Транспорт Севера», создается сессия, а в меню отображаются данные профиля внешней соцсети.

**Состояние системы после успешного входа**

- Появляется **зеленый flash «Вход выполнен»**.
- Слева отображается **открытое боковое меню**.
- Вместо кнопки «Вход» отображается **кнопка «Выход»**.
- Над кнопкой «Выход» отображается **иконка «человечек»** и **«Имя Фамилия»** зарегистрированного профиля.

**Выход из системы**

- Для выполнения выхода используется **кнопка «Выход»** в боковом меню.
- После клика по кнопке «Выход» **сессия пользователя полностью аннулируется** (очищаются куки / localStorage).
- Кнопка «Выход», иконка профиля и «Имя Фамилия» **скрываются из бокового меню**.
- В боковом меню снова отображается **кнопка «Вход»**.
- Пользователь переводится в **гостевой режим** (неавторизованное состояние).
